# Version 4 — sealed

Approved 26 October 2026. The complete 15-piece, 20:1 split-casing gearbox is
preserved in both SCAD and native SolidCraft form. Native true and 3dpr pieces,
linked layouts, STEP/STL exports, hardware-inclusive Blender animations, source,
tests and successful build attempts are included in version_4.zip.

The archive also contains the referenced shared helper sources under dependencies/.
Reproduction requires the configured SolidCraft/runtime and local OOBB/OOMP tools.
Absolute original paths remain in historical evidence. Restore the original paths
or rebase links when extracting elsewhere; never regenerate the live sealed folders.
The evidence/ directory holds immutable JSON/text acceptance records; complete
native execution attempts are archived under their original build/ paths.

Verified: 74 project tests, 30 native pieces, two native layouts, and the existing
SCAD motion/assembly reports. Native acceptance uses its documented tolerances;
the SCAD motion results are not presented as native collision certification.
All archived and live sealed catalogue files have SHA-256 entries in release.json.

Development continues in version 5 using the native SolidCraft recipe.
