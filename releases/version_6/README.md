# Version 6 — sealed

Preserves the accepted 20:1 and 16:1 native builds, the starting V6 baseline,
mixed-bearing/M6 diagnostic studies, shared-control source, explorer, tests,
native master, individual true/3dpr documents, linked layouts, STEP/STL files,
fit coupons, inherited presentation assets and verification evidence.

The primary build is the accepted 20:1 configuration_3d9262f6. Both accepted
configurations have 16 native part documents, two layouts and nine fit coupons.
Motion/installation/access checks passed: 143 sampled poses for 20:1 and 141
for 16:1. The other studies are recipe diagnostics, not accepted native builds.
Physical printing/load testing remains outstanding.

V6 requires an external Update action for coordinated whole-gearbox changes;
its rotor source documents support live local dimensions. V7 will pursue the
requested SolidCraft-only design driven directly by the Parameters menu.

version_6.zip contains the source snapshot and generated assets. Every archive
entry and live sealed catalogue file has a SHA-256 entry in release.json.
evidence/ exposes immutable JSON/text records. Earlier inherited records still
refer to the sealed V5 evidence. Original absolute paths remain in historical
links; restore them or rebase links when extracting elsewhere.
