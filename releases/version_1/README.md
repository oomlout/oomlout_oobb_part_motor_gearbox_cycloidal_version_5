# Version 1 - sealed

Approved 24 October 2026: 12:1 reduction, 1.5 mm eccentricity, M6 input shaft, 6705/6810 bearings. Includes the complete exploded hardware animation.

`version_1.zip` preserves the source, populate inputs, generated SCAD/STL, GIF/MP4, and validation reports. `release.json` records SHA-256 checksums. The exported SCAD files are portable; rebuilding Python sources requires the local OOBB/OOMP dependencies. Extract to a separate folder when inspecting or reproducing this release.

The version 1 parts remain available in the main parts directory. Normal generation skips sealed catalogue entries. Active development continues as version 2.
